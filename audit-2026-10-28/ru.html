Определение и смысл

Что такое квадратный корень (Racine Carrée)?

«Racine carrée» — французское обозначение квадратного корня. Это одно из фундаментальных математических понятий, ежедневно используемое школьниками, студентами и инженерами по всему миру.

Квадратный корень — это число, которое при умножении само на себя дает исходное число. Если умножить 7 на 7, получится 49. Значит, квадратный корень из 49 равен 7. Это операция, обратная возведению в квадрат.

Математически квадратным корнем из x называется число y такое, что y × y = x (или y² = x).

Обозначения и степени

Обозначение квадратного корня: символ √ и x^(1/2)

Символ √ называется радикалом. Запись √36 ставит вопрос: какое число, умноженное само на себя, дает 36? Ответ: 6.

√ Знак извлечения корня
36 Подкоренное число
6 Арифметический корень

Каждое выражение состоит из трех частей: знака радикала, подкоренного числа и корня.

Квадратный корень также можно записывать в виде дробной степени:

√x = y  &Longleftrightarrow  y² = x Standard mathematical radical sign
x^(1/2) = √x  &Longleftrightarrow  49^(1/2) = 7 Fractional power notation used in advanced algebra
Math.sqrt(x) /* JavaScript */  |  x ** 0.5 /* Python */ Syntax used in programming and scientific calculators

Обе записи математически равнозначны. В языках программирования широко используется запись x^(1/2).

Формула

Какова формула квадратного корня?

Квадратный корень определяется через фундаментальное математическое соотношение:

If y = √x, then y × y = x  (or y² = x)

Простыми словами: полученное число при умножении само на себя обязано вернуть исходное значение.

Арифметический (главный) корень

Главный арифметический корень — это неотрицательное число. Хотя и 5, и -5 в квадрате дают 25, по международному стандарту √25 = 5.

Principal Root √25 = +5
Dual Algebraic Solutions x² = 25 ⇒ x = ±5
Свойства корней

Пять главных свойств квадратного корня

Эти правила позволяют быстро упрощать и преобразовывать алгебраические выражения:

1
1. Правило произведения
√(a × b) = √a × √b (для a ≥ 0, b ≥ 0)
√(a × b) = √a × √b

Пример: √(4 × 9) = √4 × √9 = 2 × 3 = 6. Напрямую: √36 = 6.

Позволяет выносить множители из-под корня (например, √72 = √(36 × 2) = 6√2).

2
2. Правило частного
√(a / b) = √a / √b (для a ≥ 0, b > 0)
√(a ÷ b) = √a ÷ √b

Пример: √(16/4) = √16 / √4 = 4 / 2 = 2. Напрямую: √4 = 2.

Позволяет извлекать корень из дроби отдельно для числителя и знаменателя.

3
3. Правило степени
√(a²) = |a| (модуль числа a)
√(a²) = |a|

Пример: √(7²) = √49 = 7. Квадрат и корень взаимно уничтожаются.

Возведение в квадрат и извлечение корня возвращают исходное число по модулю.

4
4. Самоумножение
√a × √a = a
√a × √a = a

Пример: √13 × √13 = 13. √5 × √5 = 5.

Умножение корня на самого себя снимает радикал. Важно для избавления от иррациональности в знаменателе (1/√5 = √5/5).

5
5. Вложенный корень
√(√a) = a^(1/4) (корень четвертой степени)
√(√a) = a^(1/4)

Пример: √(√16) = √4 = 2. И 16^(1/4) = 2.

Корень из корня дает корень 4-й степени из исходного числа.

Метод 3: Столбиком («Уголком»)

Классический ручной алгоритм для нахождения корня с любой точностью.

  • 1. Разбейте число на грани по две цифры от запятой
  • 2. Подберите наибольший квадрат для первой грани
  • 3. Вычтите, снесите следующую пару цифр и удвойте текущий корень
  • 4. Подберите следующую цифру и повторяйте шаги

Позволяет точно извлекать корни вручную без калькулятора.

Метод 4: Оценка и метод приближений

Для быстрого вычисления в уме:

Пример: Оценка √50
  • 1. Найдите соседние квадраты: 49 < 50 < 64 (значит, 7 < √50 < 8)
  • 2. Число 50 очень близко к 49, поэтому ответ чуть больше 7
  • 3. Приближенный ответ: ~7,07 (точное значение: 7,0711...)

Этот принцип лежит в основе вавилонского метода (метод Герона / Ньютона).

Дроби и десятичные числа

Квадратные корни из десятичных чисел и дробей

Извлечение корня из дробей подчиняется стандартным алгебраическим законам:

Корни из десятичных дробей

Конечные десятичные дроби вычисляются с учетом знаков после запятой:

  • √0.25 = 0.5  (0.5 × 0.5 = 0.25)
  • √0.49 = 0.7  (0.7 × 0.7 = 0.49)
  • √2.25 = 1.5  (1.5 × 1.5 = 2.25)

Корни из обыкновенных дробей

По правилу частного извлекайте корень отдельно из числителя и знаменателя:

  • √(1/4) = √1 / √4 = 1/2
  • √(9/16) = √9 / √16 = 3/4
  • √(25/49) = √25 / √49 = 5/7

Проверьте любую дробь на калькуляторе выше для проверки вычислений.

Комплексные числа

Корни из отрицательных чисел и мнимая единица i

Среди действительных чисел отрицательные числа корней не имеют, так как квадрат любого действительного числа положителен.

Для этого вводится мнимая единица i (где i² = -1). Формула: √(-a) = √a × i для любого a > 0.

i = √(−1)  &Longleftrightarrow  i² = −1  &Longleftrightarrow  √(−a) = √a × i
Примеры с отрицательными числами
√(-1) → i
√(-4) → 2i
√(-9) → 3i
√(-16) → 4i
√(-81) → 9i

Эти числа образуют систему комплексных чисел (a + bi), необходимую в электротехнике, квантовой физике и обработке сигналов.

Взаимно обратные действия

Разница между возведением в квадрат и извлечением корня

Возведение в квадрат и извлечение корня — взаимно обратные действия, как сложение и вычитание.

8 Number
Squaring (8²) →
← Square Root (√64)
64 Square (n²)
Операция Что делает Пример
Возведение в квадрат (x²) Умножает число само на себя 8² = 64
Извлечение корня (√x) Находит число, которое при умножении на себя дает x √64 = 8

Одно действие отменяет другое: √(8²) = √64 = 8, и (√64)² = 8² = 64.

Поскольку возведение в квадрат стирает знаки, действует правило: √(a²) = |a|.

Частые вопросы

Часто задаваемые вопросы (FAQ)

Как пользоваться калькулятором квадратного корня?

Введите число в поле вверху и нажмите «Рассчитать». Вы моментально получите десятичный результат, упрощенный радикал и шаги решения.

Что означает термин «racine carrée»?

«Racine carrée» — французское название квадратного корня. Означает число, которое при умножении на себя дает исходное значение.

Калькулятор поддерживает отрицательные числа?

Да. Для отрицательных чисел калькулятор находит комплексный результат с мнимой единицей i (например, √(-16) = 4i).

В чем разница между квадратным и кубическим корнем?

Квадратный корень ищет число, умножаемое дважды (степень 2). Кубический — число, умножаемое трижды (степень 3).

Как извлечь корень без калькулятора?

Разложением на множители, методом столбиком («уголком») или методом приближений Ньютона.

Что такое точный квадрат?

Целое число, корень из которого также является целым числом (1, 4, 9, 16, 25, 36, 49, 64, 81, 100).

Все ли корни являются рациональными числами?
