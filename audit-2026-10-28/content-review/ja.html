定義と基礎

平方根（Racine Carrée）とは？

「Racine carrée」は平方根を表すフランス語です。世界中の学習者や技術者に親しまれている最も基本的な数学的概念の一つです。

平方根とは、自分自身を2回掛け合わせたときに元の数になる値のことです。7 × 7 = 49 なので、49の平方根は7になります。これは2乗（平方）の逆演算です。

数式では、x の平方根とは y × y = x（または y² = x）を満たす数 y を指します。

記法と指数

平方根の記法: √ 記号と x^(1/2)

根号記号 √ は平方根を表す世界標準の記号です。√36 は「2乗して36になる数は何か」を表し、答えは6です。

√ 根号（ルート記号）
36 根号の中の数
6 非負の主平方根

平方根の表現は、根号記号・被開数・根（結果）の3要素から成ります。

平方根は分数指数を用いて表すこともできます:

√x = y  &Longleftrightarrow  y² = x Standard mathematical radical sign
x^(1/2) = √x  &Longleftrightarrow  49^(1/2) = 7 Fractional power notation used in advanced algebra
Math.sqrt(x) /* JavaScript */  |  x ** 0.5 /* Python */ Syntax used in programming and scientific calculators

両者は数学的に全く同一です。プログラミング言語では通常 x^(1/2) が用いられます。

基本公式

平方根の定義式

平方根は以下の逆演算関係によって定義されます:

If y = √x, then y × y = x  (or y² = x)

得られた数を2回掛け合わせると、必ず元の数値に戻るという性質です。

主平方根の規約

国際的な数学規約により、√ 記号は常に非負（正または0）の「主平方根」を表します。5と-5の双方が2乗で25になりますが、√25 = 5 と定めます。

Principal Root √25 = +5
Dual Algebraic Solutions x² = 25 ⇒ x = ±5
計算規則

平方根の5大基本性質

代数計算や根号の変形で必須となる5つの公式です:

1
1. 積の公式
√(a × b) = √a × √b (a ≥ 0, b ≥ 0)
√(a × b) = √a × √b

例: √(4 × 9) = √4 × √9 = 2 × 3 = 6。直接計算: √36 = 6。

数を因数に分解して根号の外に出す際に使います（例: √72 = 6√2）。

2
2. 商の公式
√(a / b) = √a / √b (a ≥ 0, b > 0)
√(a ÷ b) = √a ÷ √b

例: √(16/4) = √16 / √4 = 4 / 2 = 2。直接計算: √4 = 2。

分数の分子と分母の平方根を別々に計算できます。

3
3. 累乗の公式
√(a²) = |a| (aの絶対値)
√(a²) = |a|

例: √(7²) = √49 = 7。2乗と根号は互いに打ち消し合います。

常に正の絶対値が得られます。

4
4. 同一根の積
√a × √a = a
√a × √a = a

例: √13 × √13 = 13。√5 × √5 = 5。

同じ根号同士を掛けると根号が外れます（分母の有理化: 1/√5 = √5/5）。

5
5. 二重根号
√(√a) = a^(1/4) (4乗根)
√(√a) = a^(1/4)

例: √(√16) = √4 = 2。16^(1/4) = 2。

根号の根号は元の数の4乗根になります。

計算方法

平方根の求め方: 4つの手法

状況に応じて使い分けられる4種類の手法があります:

手法1: 本オンライン計算機（最速）

数値を入力して「計算」を押すだけで、即座に正確な解と根号の簡約形が得られます。

上部の計算機へ戻る

手法2: 素因数分解法（平方数に最適）

整数や平方数の計算に最適です。

素因数分解の例
  • 1. 数値を素数の積に分解する
  • 2. 同じ素因数を2個ずつのペアにまとめる
  • 3. 各ペアから1個を根号の外に出す
  • 4. 外に出た因数同士を掛け合わせる
√144 → 2 × 2 × 2 × 2 × 3 × 3 → (2×2) × (2×2) × (3×3) → 2 × 2 × 3 = 12
√72 → 2 × 2 × 2 × 3 × 3 → 6 stays outside, 2 stays inside → 6√2 (≈8.485)

手法3: 開平法（筆算法）

電卓なしで任意の桁数まで正確に求められる筆算アルゴリズムです。

  • 1. 小数点を基準に2桁ずつ区切る
  • 2. 最初の区切りに入る最大の平方数を見つける
  • 3. 引き算をして次の2桁を下ろし、得られた数を2倍する
  • 4. 試行数字を見つけて手順を繰り返す

紙と鉛筆だけで厳密な小数を求める伝統的手法です。

手法4: 挟み撃ち近似法（暗算向け）

手元に電卓がないときのおおよその暗算に便利です:

例: √50の近似
  • 1. 前後の平方数を探す: 49 < 50 < 64（つまり 7 < √50 < 8）
  • 2. 50は49に極めて近いため、√50は7をわずかに上回る
  • 3. 近似値: 約7.07（厳密値: 7.0711...）

バビロニア法（ニュートン法）の基礎となる考え方です。

複素数

負の数の平方根と虚数単位 i

実数の範囲では、実数を2乗すると常に正になるため、負の数の平方根は存在しません。

これに対応するため、数学では虚数単位 i (i² = -1) を定義しています。公式: √(-a) = √a × i (a > 0)。

i = √(−1)  &Longleftrightarrow  i² = −1  &Longleftrightarrow  √(−a) = √a × i
負の数の計算例
√(-1) → i
√(-4) → 2i
√(-9) → 3i
√(-16) → 4i
√(-81) → 9i

これらは複素数 (a + bi) を構成し、電気工学や量子力学で不可欠です。

逆演算

2乗（平方）と平方根の違い

2乗することと平方根を求めることは、加算と減算のように互いに逆の演算です。

8 Number
Squaring (8²) →
← Square Root (√64)
64 Square (n²)
演算 意味 例
2乗する (x²) 数を自分自身と掛け合わせる 8² = 64
平方根をとる (√x) 2乗して x になる数を見つける √64 = 8

互いに逆の操作です: √(8²) = √64 = 8, および (√64)² = 8² = 64。

2乗すると符号が消えるため、主平方根では √(a²) = |a| が成り立ちます。

実社会の応用

日常生活や専門分野における平方根の活用

平方根は科学・工学・日常生活のあらゆる場面に登場します:

建築・設計

三平方の定理（ピタゴラスの定理: a² + b² = c²）を用いた対角線や屋根の勾配計算（例: √(3² + 4²) = 5m）。

金融・投資分析

ポートフォリオのリスクや価格変動幅を表す標準偏差は、分散の平方根として計算されます。

物理・工学

自由落下の速度（v = √(2gh)）、振り子の周期、交流回路のインピーダンス計算。

CG・プログラミング

3D空間のユークリッド距離計算、当たり判定、探索アルゴリズムの計算量 √n。

身近な広さの測定

床面積から部屋の辺の長さを算出: 64㎡の部屋の1辺は √64 = 8m。

よくある質問

よくある質問（FAQ）

平方根計算機の使い方は？

上の枠に数字を入力して「計算」をクリックするだけです。小数解、簡約形、計算の道筋が瞬時に表示されます。

「racine carrée」とはどういう意味ですか？

フランス語で「平方根（スクエアルート）」を意味し、2乗するとその数になる値を指します。

負の数（マイナス）の計算はできますか？

はい。虚数単位 i を用いた複素数解（例: √(-16) = 4i）とステップ解説を表示します。

平方根と立方根の違いは？

平方根は2回掛ける数（2乗根）、立方根は3回掛ける数（3乗根）を求めます。

電卓なしで平方根を求めるには？

素因数分解、筆算による開平法、またはバビロニア法による近似計算を用います。

完全平方数とは？

平方根が整数になる整数のことです（1, 4, 9, 16, 25, 36, 49, 64, 81, 100 など）。

平方根はすべて有理数ですか？

いいえ。完全平方数のみが有理数になり、その他の数はすべて無理数です。

利用料金はかかりますか？

いいえ。当サイトのツールは完全無料で回数制限もなくご利用いただけます。

分数や小数のルートも計算できますか？

はい。小数や分数をそのまま入力して正確に求められます。

主平方根とは何ですか？

√ 記号が表す非負（0以上）の解のことを指します。
