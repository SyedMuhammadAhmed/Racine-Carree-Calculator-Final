정의 및 개념

제곱근 (Racine Carrée)이란 무엇인가요?

«Racine carrée»는 제곱근을 뜻하는 프랑스어입니다. 전 세계 학생들이 가장 많이 검색하는 기초 수학 개념 중 하나입니다.

제곱근이란 어떤 수를 자기 자신과 곱했을 때 원래 수가 나오는 값을 말합니다. 7에 7을 곱하면 49가 되므로, 49의 제곱근은 7입니다. 즉, 제곱의 역연산입니다.

수학적으로 x의 제곱근은 y × y = x (또는 y² = x)를 만족하는 수 y를 뜻합니다.

기호 및 지수

제곱근 표기법: √ 기호와 x^(1/2)

기호 √는 표준 근호입니다. √36은 '자기 자신과 곱해 36이 되는 수는 무엇인가?'를 묻는 것이며 답은 6입니다.

√ 근호 기호
36 근호 안의 수
6 주제곱근 결과

근호 식은 근호 기호, 피제곱근수, 제곱근의 세 부분으로 구성됩니다.

제곱근은 분수 지수 형태로도 표기할 수 있습니다:

√x = y  &Longleftrightarrow  y² = x Standard mathematical radical sign
x^(1/2) = √x  &Longleftrightarrow  49^(1/2) = 7 Fractional power notation used in advanced algebra
Math.sqrt(x) /* JavaScript */  |  x ** 0.5 /* Python */ Syntax used in programming and scientific calculators

두 형태는 수학적으로 완전히 동일합니다. 프로그래밍 언어에서는 x^(1/2) 형태를 자주 사용합니다.

핵심 공식

제곱근의 기본 공식

제곱근은 다음과 같은 역연산 관계로 정의됩니다:

If y = √x, then y × y = x  (or y² = x)

구한 값을 자기 자신과 곱했을 때 원래 수가 나와야 한다는 원리입니다.

주제곱근 규칙

국제 수학 규약상 √ 기호는 항상 음이 아닌 양의 '주제곱근'을 의미합니다. 5와 -5 모두 제곱하면 25이지만 √25 = 5로 약속합니다.

Principal Root √25 = +5
Dual Algebraic Solutions x² = 25 ⇒ x = ±5
핵심 성질

제곱근의 5가지 핵심 성질

대수 연산과 근호 단순화에 필수적인 법칙들입니다:

1
1. 곱셈 법칙
√(a × b) = √a × √b (a ≥ 0, b ≥ 0)
√(a × b) = √a × √b

예: √(4 × 9) = √4 × √9 = 2 × 3 = 6. 직접 계산: √36 = 6.

인수를 분리하여 근호를 간단히 할 수 있습니다 (예: √72 = 6√2).

2
2. 나눗셈 법칙
√(a / b) = √a / √b (a ≥ 0, b > 0)
√(a ÷ b) = √a ÷ √b

예: √(16/4) = √16 / √4 = 4 / 2 = 2. 직접 계산: √4 = 2.

분수의 분자와 분모를 각각 분리하여 제곱근을 계산합니다.

3
3. 거듭제곱 법칙
√(a²) = |a| (a의 절댓값)
√(a²) = |a|

예: √(7²) = √49 = 7. 제곱과 근호가 상쇄됩니다.

원래 수의 양수 절댓값을 반환합니다.

4
4. 자기 자신과의 곱
√a × √a = a
√a × √a = a

예: √13 × √13 = 13. √5 × √5 = 5.

근호를 벗겨낼 때 사용됩니다 (분모의 유리화: 1/√5 = √5/5).

5
5. 이중근호 법칙
√(√a) = a^(1/4) (네제곱근)
√(√a) = a^(1/4)

예: √(√16) = √4 = 2. 그리고 16^(1/4) = 2.

제곱근의 제곱근은 네제곱근이 됩니다.

제곱근을 구하는 4가지 방법

상황에 따라 네 가지 계산 방식을 활용할 수 있습니다:

방법 1: 본 온라인 계산기 활용 (가장 빠름)

계산기로 이동

방법 2: 소인수분해법 (완전제곱수용)

정수와 완전제곱수에 가장 효과적입니다.

소인수분해 예시
  • 1. 숫자를 소인수분해한다
  • 2. 같은 소인수를 둘씩 짝짓는다
  • 3. 각 짝에서 하나씩을 근호 밖으로 꺼낸다
  • 4. 밖으로 꺼낸 숫자들을 서로 곱한다
√144 → 2 × 2 × 2 × 2 × 3 × 3 → (2×2) × (2×2) × (3×3) → 2 × 2 × 3 = 12
√72 → 2 × 2 × 2 × 3 × 3 → 6 stays outside, 2 stays inside → 6√2 (≈8.485)

방법 3: 개평법 (손으로 직접 계산)

계산기 없이 소수점 아래까지 정확히 구하는 전통 필산법입니다.

  • 1. 소수점을 기준으로 두 자리씩 묶는다
  • 2. 첫 묶음에 들어가는 가장 큰 제곱수를 찾는다
  • 3. 빼고 다음 두 자리를 내린 뒤 제곱근을 2배한다
  • 4. 다음 자릿수를 찾아 반복한다

손으로 직접 풀 때 유용한 고전적 방법입니다.

방법 4: 암산 어림셈법

머릿속으로 빠르게 근사값을 추정할 때 유용합니다:

예: √50 어림하기
  • 1. 인접한 완전제곱수 찾기: 49 < 50 < 64 (즉 7 < √50 < 8)
  • 2. 50은 49에 매우 가까우므로 7보다 살짝 큼
  • 3. 어림값: 약 7.07 (실제값: 7.0711...)

바빌로니아 법(헤론 / 뉴턴-랩슨 법)의 기초 원리입니다.

소수와 분수

소수와 분수의 제곱근

제곱근은 소수와 분수에도 동일하게 적용됩니다:

소수의 제곱근

소수점 위치를 고려하여 계산합니다:

  • √0.25 = 0.5  (0.5 × 0.5 = 0.25)
  • √0.49 = 0.7  (0.7 × 0.7 = 0.49)
  • √2.25 = 1.5  (1.5 × 1.5 = 2.25)

분수의 제곱근

나눗셈 법칙에 따라 분자와 분모를 분리하여 계산합니다:

  • √(1/4) = √1 / √4 = 1/2
  • √(9/16) = √9 / √16 = 3/4
  • √(25/49) = √25 / √49 = 5/7

위 계산기에 분수를 넣어 직접 확인해보세요.

복소수

음수의 제곱근과 허수단위 i

실수 범위에서는 어떤 실수를 제곱해도 양수가 되므로 음수의 제곱근이 없습니다.

이를 위해 허수단위 i(i² = -1)를 정의합니다. 공식: √(-a) = √a × i (a > 0).

i = √(−1)  &Longleftrightarrow  i² = −1  &Longleftrightarrow  √(−a) = √a × i
음수 제곱근 예시
√(-1) → i
√(-4) → 2i
√(-9) → 3i
√(-16) → 4i
√(-81) → 9i

이는 복소수(a + bi)를 이루며 전자공학과 양자물리학에서 필수입니다.

역연산 관계

제곱하기와 제곱근 구하기의 차이

제곱과 제곱근은 덧셈과 뺄셈처럼 서로 반대되는 역연산입니다.

8 Number
Squaring (8²) →
← Square Root (√64)
64 Square (n²)
연산 기능 예시
제곱 (x²) 숫자를 자기 자신과 곱함 8² = 64
제곱근 (√x) 제곱해서 x가 되는 수를 찾음 √64 = 8

서로를 원래대로 되돌립니다: √(8²) = √64 = 8, 및 (√64)² = 8² = 64.

제곱하면 부호가 사라지므로: √(a²) = |a|.

자주 묻는 질문 (FAQ)

계산기는 어떻게 사용하나요?

위 입력란에 숫자를 넣고 계산 버튼을 누르면 정확한 소수값과 기약 근호 형태가 즉시 나옵니다.

«racine carrée»는 무슨 뜻인가요?

«racine carrée»는 프랑스어로 제곱근을 의미합니다.

음수도 계산할 수 있나요?

네, 허수단위 i를 사용한 복소수 형태로 계산해 드립니다 (예: √(-16) = 4i).

제곱근과 세제곱근의 차이는?

제곱근은 2번 곱해지는 수(2제곱), 세제곱근은 3번 곱해지는 수(3제곱)를 구합니다.

계산기 없이 제곱근을 어떻게 구하나요?

소인수분해법, 나눗셈 필산법(개평법), 바빌로니아 어림셈법을 사용합니다.

완전제곱수란 무엇인가요?

제곱근이 정수인 수입니다 (1, 4, 9, 16, 25, 36, 49, 64, 81, 100).

모든 제곱근은 유리수인가요?

아닙니다. 완전제곱수만 유리수이며 그 외의 수는 모두 무리수입니다.

이 계산기는 무료인가요?

네, 100% 무료이며 별도의 설치나 가입 없이 웹 브라우저에서 바로 사용하실 수 있습니다.

분수나 소수도 계산되나요?

네, 분수와 소수 모두 정확히 계산됩니다.

주제곱근이란 무엇인가요?

√ 기호가 기본적으로 가리키는 0 이상의 양수 제곱근을 뜻합니다.
