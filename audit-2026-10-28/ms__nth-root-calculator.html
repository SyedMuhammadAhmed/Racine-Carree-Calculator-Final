Apakah Itu Punca Kuasa n (Nth Root)?

Anda mungkin sudah biasa dengan punca kuasa dua (darjah 2) dan punca kuasa tiga (darjah 3). Namun bagaimana jika anda perlu mengira punca kuasa 4, 5 atau lebih tinggi? Kalkulator punca kuasa n ini dibina khusus untuk menjawabnya.

Punca kuasa n mengitlak konsep mencari punca untuk sebarang pendaraban: apakah nombor yang apabila didarabkan dengan dirinya sendiri sebanyak n kali menghasilkan nilai ini?

1. Indeks Punca (Darjah n)

Nombor kecil di sebelah kiri atas simbol punca. Menentukan bilangan faktor seiras. Jika ditinggalkan, nilainya 2 (punca kuasa dua).

2. Simbol Punca & Vinculum

Simbol pengendali matematik (√). Palang atas mendatar (vinculum) mengumpulkan nilai di bawah punca.

3. Radikan (x)

Nilai di bawah simbol punca. Dengan n genap, nilainya mesti bukan negatif (x ≥ 0) untuk menghasilkan penyelesaian nyata.

4. Punca Utama (y)

Hasil nyata bukan negatif. Bagi ⁴√81, punca utama ialah 3 kerana 3⁴ = 81.

Contoh: Punca kuasa 4 bagi 16 ialah 2, kerana 2 × 2 × 2 × 2 = 16.

Formula dan Takrif Punca Kuasa n

Punca kuasa n ditakrifkan sebagai songsangan kepada operasi eksponen kuasa:

ⁿ√x = x^(1/n)

Jika y = ⁿ√x, maka yⁿ = x. Menguasakan punca y dengan n mengembalikan nilai radikan x.

ⁿ√(x^m) = (ⁿ√x)^m = x^(m/n)

Algoritma Berangka

Kaedah Lelaran Newton-Raphson

Pemproses komputer mengira punca sewenang-wenangnya secara lelaran menggunakan:

x_(k+1) = (1/n) · [ (n - 1)·x_k + A / (x_k^(n-1)) ]
Demonstrasi: Anggaran ∛30 (n = 3, A = 30)
  1. Anggaran awal: Memandangkan 3³ = 27, pilih x₀ = 3.
  2. Lelaran 1: x₁ = (1/3) · [2(3) + 30/3²] = (1/3) · [6 + 3.3333] = 3.1111.
  3. Lelaran 2: x₂ = (1/3) · [2(3.1111) + 30/(3.1111²)] = 3.1072.
  4. Pengesahan: 3.1072³ = 29.999. Hanya dalam dua lelaran diperoleh ketepatan 4 tempat perpuluhan.

Simbol Punca Kuasa n: Apakah Maksud ⁿ√?

Punca kuasa n menggunakan simbol radikal (√) dengan indeks kecil n:

ⁿ√x «punca kuasa n bagi x»
n = indeks punca Darjah kuasa punca
x = radikan Nombor di dalam radikal

Jika indeks tidak dicatat (√x), ia membawa maksud n = 2. Dalam bentuk eksponen pecahan:

ⁿ√x = x^(1/n). Kedua-dua notasi menggambarkan operasi matematik yang sama.

Soalan Lazim

Soalan Lazim Mengenai Punca Kuasa n

Apakah perbezaan antara punca kuasa dua dan punca kuasa tiga?

Punca kuasa dua berindeks 2, manakala punca kuasa tiga berindeks 3 dan mempunyai penyelesaian nyata bagi nombor negatif.

Apakah maksud indeks n bagi punca kuasa ke-n?

Indeks n merupakan darjah punca kuasa dalam ⁿ√x (2 untuk kuasa dua, 3 untuk kuasa tiga, dan seterusnya).

Bolehkah mencari punca kuasa ke-n bagi nombor negatif?

Jika darjah n adalah ganjil (3, 5, 7...) penyelesaian nyata wujud. Jika genap (2, 4, 6...) tiada penyelesaian nyata.

Adakah kalkulator ini percuma?

Ya, alat kami 100% percuma tanpa perlu mendaftar atau memuat turun.

Fakta Utama:

Punca kuasa n menentukan nilai yang apabila didarab n kali menghasilkan x. Indeks ganjil membenarkan nombor negatif nyata; indeks genap memerlukan nilai positif.
